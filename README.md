# Аттестация 1 — Система расписания

Проект для валидации и хранения университетского расписания (ООП, Java 17).

## Возможности
* Поддержка лекций, практик и лабораторных работ.
* Проверка конфликтов при добавлении пары (занятость аудитории, преподавателя или группы).
* Подсчет учебных часов преподавателя.
* Вывод расписания по группам, преподам и аудиториям.

## Структура
* `Models.java` — сущности (Teacher, Classroom, Group, Subgroup, LessonNumber).
* `Lesson.java` — иерархия предметов (Lecture, Practice, LabWork).
* `Manager.java` — логика добавления и проверки накладок.
* `ScheduleManagerTest.java` — unit-тесты (JUnit 5).

## Запуск
Класса `Main` нет, проверка работы логики выполняется через тесты.
Запустить файл `ScheduleManagerTest.java` в IDE (IntelliJ IDEA) или через Gradle/Maven:
```bash
./gradlew test
